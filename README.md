# FitBulldozers
sport/fitness applicatie voor project 2

ontmoet onze revolutionaire website: FitBulldozer!
Gebruik onze website om je fitneesvoortgang bij te houden.
Onze website kan grafieken genereren, voortgang bijhouden in workouts, stappenteller en calorieën verbrand/binnengekregen. De mogelijkheden zijn eindloos!
Zelfs voor beginners hebben we uitleg filmpjes met namen van de workouts en plaatjes die het snel aangeven.
