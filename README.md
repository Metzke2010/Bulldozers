# FitBulldozers
Sport/fitness applicatie voor project 2

Ontmoet onze revolutionaire website: FitBulldozer!
Gebruik onze website om je fitneesvoortgang bij te houden.
Onze website kan grafieken genereren, voortgang bijhouden in workouts, stappenteller en calorieën verbrand/binnengekregen. De mogelijkheden zijn eindeloos!
Zelfs voor beginners hebben we uitleg filmpjes met namen van de workouts en plaatjes die het snel aangeven.

Klik op een nieuwe workout toevoegen om een workout die je hebt gedaan toe te voegen. 
Als je vervolgens naar overzicht gaat en naar beneden scrollt dan kan je een grafiek zien bij de workout die je hebt toegevoegd
ook kan je doelen stellen op de doelen pagina door bovenin de doelen die wilt doen te selecteren.
onderaan kan je je voortgang van het doel bijhouden.
door op de plaatjes te klikken bij workout uitleg wordt je naar een youtube filmpje begeleidt om de workout te bekijken.

In een bijgevoegd document staat alles oor de interactie.
